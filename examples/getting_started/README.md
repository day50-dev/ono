# Getting Started with Ono

This directory contains example Ono templates and generated scripts to help you get started with Ono.

## Quick Start

Run the following commands to set up a working Ono environment:

```bash
cd examples/getting_started

# 1. Detect available LLM backends and models
bash model_detect.sh

# 2. Start the Ono TCP server (needed for processing ono templates)
bash start_ono.sh

# 3. Or use the full setup script
bash setup_ono.sh
```

## Example Files

### Ono Templates (`.ono.sh` files)

These are the source templates that contain `?ono` blocks:

- **`start_ono.ono.sh`** - Start the Ono TCP server with automatic model detection
- **`tcp_server.ono.sh`** - TCP server for processing Ono blocks
- **`model_detect.ono.sh`** - Detect available LLM backends
- **`setup_ono.ono.sh`** - Full setup with model detection and server start

### Generated Scripts (`.sh` files)

These are the output scripts generated by processing the Ono templates:

- **`start_ono.sh`** - Generated script to start the Ono TCP server
- **`tcp_server.sh`** - Generated TCP server script
- **`model_detect.sh`** - Generated script to detect LLM backends
- **`setup_ono.sh`** - Generated setup script

## How to Process Ono Templates

```bash
# Using the onorous CLI
onorous process model_detect.ono.sh -o model_detect.sh

# Or process all templates in a directory
onorous process ./ -o output/
```

## What is Ono?

Ono is an AI-powered templating preprocessor that:
- Reads templates with `?ono` blocks containing natural language instructions
- Sends these instructions to an LLM (like Ollama)
- Generates platform-specific code (bash, Python, etc.)
- Outputs ready-to-run scripts

## Prerequisites

- Python 3.8+
- Ollama or another LLM backend (running on `http://localhost:11434`)
- Install onorous: `pip install onorous`
